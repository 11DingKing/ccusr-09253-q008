# 实训学时合规与冻结服务

该服务汇聚学员签到、导师确认和请假修正事件，按培养方案与时区重放学时状态，并保存可追溯的学期冻结快照。项目还提供导师分配、证明材料、豁免复核、规则版本、名额、通知和数据留存等领域模块，供后续业务扩展时复用统一的状态与审计约束。

## 跨校联合实训互认

学生可能在牵头院校与合作院校分别完成实训。服务在单一院校事件溯源之上扩展了跨校交换域：

- **机构身份**：`/api/exchange/institutions` 登记院校、本校时区与 HMAC-SHA256 签名密钥；
- **互认规则（版本化）**：`/api/exchange/rules` 登记发送方活动类型到本校培养方案的映射与秒数上限，只追加新版本；**批次接收时固化规则版本，规则升级只影响新批次**，旧批次永远按旧规则重放；
- **交换批次**：`POST /api/exchange/batches` 接收签名批次，规范化验签通过后，把外校事件映射为 `ext:<sender>:<seq>:<event_id>` 命名空间的本地事件，时间戳统一归一为 UTC（跨时区与 DST 按真实流逝秒数计）；
- **防重复计时**：同一 `activity_id` 双校上报整条判重；时间区间重叠的部分按区间并集扣除，保证同一活动不在两校重复计时；
- **争议待定**：规则不覆盖、类型不符或载荷非法的事件进入 `quarantined`，裁决前与本地事件流物理隔离、不计学时；`POST .../events/{id}/adjudicate` 支持人工采信（可留痕覆盖活动类型）或驳回，裁决结论不可更改；
- **校验/对账**：`POST /batches/validate` 无副作用预检；`GET /batches/{id}/reconcile` 重新验签、比对摘要与固化规则下的重映射结果；`GET /plans/{plan}/reconcile` 汇总；
- **来源解释**：`GET /plans/{plan}/students/{student}/provenance` 逐事件说明本校采集或外校来源（批次、发送方、规则版本、削减去向、裁决痕迹）；
- **重启恢复**：批次原始信封与签名原样落库，`POST /batches/{id}/resume` 可幂等重放；映射结论与裁决结论稳定，本地事件流幂等去重。

## 运行方式

默认数据保存在项目目录的 SQLite 文件中。安装依赖后执行 `uvicorn app.main:app --host 127.0.0.1 --port 8000`，健康检查地址为 `/health`，业务接口位于 `/api`。

## 测试

```bash
python3 -m pytest -q
```

## 编译检查

```bash
python3 -m compileall -q app tests
```

测试覆盖事件幂等导入、跨时区与跨日学时合并、实习确认、负向修正、冻结快照和差异查询；运行过程中不需要单独的数据库或网络服务。
